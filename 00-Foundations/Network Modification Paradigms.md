# Network Modification Paradigms

Before touching any single neurotransmitter, you need the two goals every protocol in this book serves, because the same molecule can serve either goal depending on how and when you use it. The framework distinguishes **reinforcing** a network from **expanding** it, and the difference is not a matter of degree but of mechanism.

**Reinforcing** a network means making the synapses that already exist fire more strongly and hold their weight. The cellular mechanism is long-term potentiation (LTP) and synaptic consolidation: you increase the synaptic weight of existing, under-fired, or older memory traces. The agent sequence that serves this goal is *precursor → PAM/agonist → signal enhancer (breakdown inhibitor)*. You load the raw material, then amplify the natural signal, then slow the breakdown so the signal lingers long enough to drive CaMKII and pull hidden AMPA receptors to the surface.

**Expanding** a network means building new structure: new dendritic spines, more receptor density, and novel cluster connections. The cellular mechanism is receptor upregulation, synaptogenesis, and neurogenesis. The agent sequence is *intermittent antagonist → neurotrophic growth stimulators → dense influx*. You first create a mild deficit signal that prompts the neuron to synthesize fresh receptors, then flood the newly upregulated system with growth factors, then drive dense synaptic activity into the new architecture.

The reason the distinction matters is that the two goals pull in opposite directions on the homeostatic dial. A short, massive burst of direct agonists produces temporary hyper-focus followed by rapid homeostatic **down-regulation** — the network shrinks its own receptors in response to over-stimulation. True structural growth takes over a month of low-intensity, cyclical prompts. So the whole book is organized around doing the right thing at the right frequency: reinforce with short, well-timed cycles; expand with long, patient, intermittent cycles.

Every neurotransmitter chapter in this book follows the same shape: an **Intensification** note (the reinforce protocol) and an **Expansion** note (the expand protocol), each with a stack schedule. The schedules are built from the universal kinetic rules in [[Universal Kinetic Rules]], and the agents are chosen to be OTC, herbal, supplement, amino-acid, or vitamin wherever the original framework used a prescription-only compound — the substitution is flagged in each table.
